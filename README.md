# 🛑 Freno de Fricción (Anti-Doomscrolling)

Una extensión de navegador ligera que combate el *doomscrolling* inyectando "fricción" progresiva en las redes sociales. 

En lugar de bloquear sitios web de forma estricta (lo cual genera frustración y suele terminar en la desactivación de la herramienta), esta extensión degrada sutilmente la experiencia de usuario a medida que pasa el tiempo. Esto ayuda a recuperar el control y la consciencia del tiempo invertido, rompiendo el ciclo de dopamina de forma orgánica.

## ✨ Características

* **Enfoque no binario:** No hay bloqueos duros. Puedes seguir navegando, pero será menos estimulante.
* **Fricción progresiva:** A los 5 minutos los colores se desaturan, a los 10 minutos se reduce el contraste, etc. (Totalmente configurable).
* **Privacidad por diseño:** Todo se calcula en tu navegador. No hay servidores, ni recolección de datos, ni tracking de ningún tipo.
* **Ligero:** Escrito en JavaScript puro y CSS, sin dependencias pesadas.

## 🚀 Instalación (Modo Desarrollador)

Actualmente el proyecto está en fase de desarrollo. Para probarlo en tu navegador:

1. Clona este repositorio: `git clone https://github.com/TU_USUARIO/freno-friccion.git`
2. Abre Google Chrome o un navegador basado en Chromium y ve a `chrome://extensions/`.
3. Activa el **Modo de desarrollador** (esquina superior derecha).
4. Haz clic en **Cargar descomprimida** y selecciona la carpeta `src` de este repositorio.
5. ¡Entra a Twitter, Instagram o X y observa cómo actúa la fricción con el tiempo!

## 🛠️ Stack Tecnológico

* JavaScript (Vanilla)
* CSS3
* Chrome WebExtension API (Manifest V3)
